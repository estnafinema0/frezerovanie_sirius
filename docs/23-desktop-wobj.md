# Milling CAM для Windows x64

Распакуйте архив целиком и откройте MillingCAM.exe. Программа использует .NET Framework 4.8 и Microsoft Edge WebView2 Evergreen Runtime. Если WebView2 отсутствует, установите x64 Runtime со страницы Microsoft https://developer.microsoft.com/microsoft-edge/webview2/. Интернет нужен только для установки отсутствующего компонента. STEP и результаты обрабатываются локально.

1. На стенде наладчик калибрует TCP инструмента toolShpindel и обучает рабочий объект wobjIngot. Отметьте физический верхний угол бруска, направление положительного X и сторону положительного Y в верхней плоскости. Z определяется правилом правой руки.
2. Загрузите STEP, задайте границы бруска, добавьте и подтвердите операции. Рассчитайте программу. Для плоского примера в архиве есть examples/automatic-box.step.
3. В разделе «Координаты заготовки · wobjIngot» выберите соответствие детали реальной привязке. Стандартный вариант берёт верхний угол (Xmin,Ymin,Zmax) рассчитанного блока и направления STEP. При расчёте отдельной грани можно задать углы блока; если границы не заданы, интерфейс явно показывает использование габаритов модели. Для другого угла или поворота выберите «Три точки в STEP» и введите O, точку вдоль +X и третью точку в плоскости XY со стороны +Y. Все значения в миллиметрах и в координатах модели. После загрузки другой модели привязку задают заново.
4. Сверьте три стрелки на модели с обученными осями. При несовпадении направлений одинаковые координаты попадут в другую область бруска. Просмотрите начало и переходы. Выберите в списке «Программа» или нужную грань. Кнопка «Сохранить траекторию в wobjIngot…» сохраняет всю выбранную программу или непрерывный путь грани, включая переходы. Выбор отдельного прохода служит для просмотра. Имя файла по умолчанию prepared.poses.csv.
5. Для EGM_Force сохраните файл рядом с egm_primitives.exe. В PowerShell из этой папки проверьте его командой `.\egm_primitives.exe csv ".\prepared.poses.csv" --check`. Для этой версии EGM_Force нужна фиксированная ориентация и длительность до 57 с; ограничения действуют при воспроизведении. CAM экспортирует также пути с меняющейся ориентацией для анализа. Геометрические отметки контакта и остатка показаны для просмотра и не препятствуют экспорту.
6. CSV хранит абсолютные XYZ TCP в wobjIngot и ориентацию TCP относительно его осей (w,x,y,z). Контроллер применяет обученный wobjIngot и toolShpindel. Начальная поза робота не переносит программу; смещение фланца, длину инструмента и положение бруска в базе к CSV не прибавляют. Настольное окно занимается расчётом и сохранением. Существующий приёмник EGM_Force запускают отдельно, как указано в его README_RU.md.

Пример проверки привязки: O=(10,20,5), точка +X=(10,30,5), точка +Y=(0,20,5). Точка STEP (8,23,4) должна иметь координаты (3,2,-1) в CSV.
