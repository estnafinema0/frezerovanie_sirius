# Документация проекта FrezaEgm

Этот каталог — «память» проекта: здесь собрано всё, что нужно, чтобы понять задачу,
воспроизвести сборку и продолжить работу через месяц или передать её другому человеку.

## С чего начать

0. Понять, где мы сейчас — `../PROJECT_STATE.md`.
1. Понять задачу — `01-requirements.md`.
2. Понять, откуда берётся траектория — `03-trajectory-format.md`.
3. Понять протокол — `05-egm-protocol.md`.
4. Собрать и прогнать самотест — `07-build-vs2022.md`, `08-testing.md`.
5. Запустить симуляцию — `06-robotstudio-setup.md`, `12-runbook.md`.

## Соглашения

* Язык документов и комментариев в коде — русский; идентификаторы в коде — английские.
* Все числовые значения координат — миллиметры, если не указано иное.
* Порт EGM по умолчанию — **6510** (см. `SIO.cfg` станции).
* Ссылки на файлы даются относительно корня рабочей области.
