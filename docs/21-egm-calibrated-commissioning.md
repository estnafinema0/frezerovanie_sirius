# EGM RW6 с измеренной привязкой детали

Этот профиль предназначен для наладки. Пакет содержит симуляционный RAPID-модуль; подготовка модуля для конкретной ячейки и проверка на физическом IRC5 выполняются наладчиком.

Для постоянных адресов Ethernet один раз отредактируйте `Ethernet-IP.txt` рядом с EXE. Введите IPv4 проводного интерфейса Windows в первую строку, IPv4 IRC5 во вторую, без подписей. Запускайте `Start-Ethernet.cmd`. В этом запуске поля адресов и локальный порт UDP 6510 закреплены. Калибровку подтвердите отдельно. Чтобы изменить профиль, закройте программу, отредактируйте файл и откройте её заново.

В Windows у проводного адаптера должен быть назначен этот адрес (статически либо через резервирование DHCP). В настройках UCdevice на IRC5 Remote Address равен первой строке, Remote Port Number равен 6510. Адрес самого контроллера соответствует второй строке. Используйте назначенные для сети ячейки адреса и маску. Приложение не перенастраивает Ethernet-адаптер или IRC5. Для локальной RobotStudio по-прежнему запускайте Start-Milling.cmd.

1. Распакуйте весь Windows ZIP и запустите Start-Milling.cmd. Загрузите модель, рассчитайте и подготовьте траекторию. Скачайте CSV, чтобы проверить первые координаты и ориентацию. Ошибка проверки контакта или остаточного материала блокирует запуск.
2. Измерьте верхний угол блока (Xmin, Ymin, Zmax) и оси детали относительно базы. В режиме «Измеренная привязка детали» введите XYZ начала в миллиметрах и единичный кватернион wxyz «деталь → база». Если оси совмещены, введите 1,0,0,0. Оба флажка демонстрационной симуляции снимите.
3. Первая позиция в базе равна R × p0 + T. Первая ориентация равна R × q0. В CSV этой версии q0 уже задаёт TCP с +Z к детали: наладчик должен подтвердить, что оси измеренного инструмента соответствуют этому соглашению. Длину инструмента в XYZ дополнительно не прибавляют. Подведите TCP к рассчитанной свободной стартовой позе вручную. Неверная привязка заготовки не обнаруживается одним сравнением TCP.
4. Наладчик на копии конфигурации IRC5 проверяет RW6 и опцию EGM, задаёт UdpUc Remote Address = адрес Ethernet компьютера, Remote Port = 6510. В приложении Bind IP = этот адрес компьютера, Peer IP = Ethernet IP контроллера. Разрешите входящий UDP только от этого контроллера. Используйте отдельный RAPID-модуль, проверенное tooldata шпинделя и точку fine на старте. Симуляционный simTool из архива не используйте на стенде.
5. Начните с RobotStudio и выключенного шпинделя. Затем на стенде наладчик проверяет путь в свободном пространстве, допустимые конфигурации робота, пределы скорости и штатную аппаратную остановку. Сначала в CAM нажмите «Начать ожидание EGM», затем запустите подготовленную процедуру RAPID. Контроллер отправляет первый EgmRobot. При несовпадении стартовой позы более 0,1 мм или 0,5° приложение завершает сеанс без отправки команды. При совпадении первый EgmSensor возвращает измеренную позу; далее передаются XYZ и кватернион траектории в базе.
6. Счётчик «отправлено» и захват UDP подтверждают отправку с ПК. Принятие команд проверяйте по Event Log и движению TCP. Кнопка «Удержать» не заменяет аварийную остановку. Прежде чем переходить к резанию, подтвердите остановку при потере связи и проверьте зазоры инструмента, держателя, робота и оснастки.

До испытания на стенде подтверждены только подготовка Command Pose и локальный обмен Protobuf/UDP. Не переносите настройки безопасного движения из симуляции автоматически.
