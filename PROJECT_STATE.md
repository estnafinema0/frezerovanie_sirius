# Автоматическая программа всей модели

обход верхних и доступных боковых поверхностей по нормалям. Выбор грани просмотра

кандидаты исключаются. Контроль — `MillingAnalyzer/data/automatic-box.step`.

## Что уже работает

* **Симуляция в RobotStudio 6.08.01**: робот IRB 1600 встаёт в `home` (750, 0, 600)
  кончиком инструмента `toolPencil` и проходит **замкнутый квадрат 100×100 мм**
  (5 точек, 201 подточка при шаге 2 мм), возвращается в начало.
* **Скорость регулируется** слайдером/полем «скорость, мм/с» (5–200) и реально влияет
  на движение; шаг меняет только гладкость.
* **Обратная связь** в приложении: состояние, номер точки, цель (абсолютная поза TCP),
  фактическая поза, счётчики пакетов, MCI, моторы, сходимость.
* **Ручные команды**: `dX/dY/dZ` от первой точки и кнопка `Home (0, 0, 0)`.
* **CSV**: «Сохранить CSV» / «Загрузить CSV» — сохранение массива точек и загрузка его
  как источника траектории (требование задания, шаги 3–4).
* **Самотест без робота**: 35 проверок (файл → точки → CSV → интерполяция → protobuf →
  UDP-loopback), `ctest` проходит.

## Ключевые ошибки, которые уже пройдены (чтобы не повторять)

| Симптом | Причина | Решение |
|---|---|---|
| `50456 Close to singularity`, моторы OFF | `home` (750, 0, 300) с инструментом вверх | `home` (750, 0, 600), ориентация `[0,1,0,0]` |
| Робот едет «к себе и вниз», не доезжает | отправлялись смещения, а контроллер ждёт абсолютную позу | абсолютные координаты TCP |
| Инструмент заворачивается, уходит с траектории | включены `\Rx \Ry \Rz` при единичном кватернионе | убрать повороты |
| Трапеция вместо квадрата | цель переключалась по таймеру, робот не успевал | досылка на вершинах |
| Скорость не реагирует на настройку | низкий лимит `MaxSpeedDeviation` по умолчанию | `\MaxSpeedDeviation:=1000.0` |
| Движение «стоп-разгон» на каждой подточке | ожидание достижения каждой подточки при мелком шаге | на прямых цель движется по времени |
| `Состояние EGM: ошибка` в конце | контроллер закрывает сессию после `EGMReset` (WSAECONNRESET) | штатное завершение сессии |
| `Reference to unknown entire data toolPencil` | `toolPencil` — графика, а не `tooldata` | объявлен `PERS tooldata toolPencil` |
