# SIO.cfg с адресом EGM-устройства 192.168.125.1

Файл `SIO-192.168.125.1.cfg` — копия `SIO.cfg` системы `FrezaEGM`, в которой у
записи `UCdevice` (раздел `COM_TRP`) стоит:

```
-RemoteAdress "192.168.125.1"
-RemotePortNumber 6510
```

## Где этот адрес вообще задаётся

В приложении FrezaEgm IP-адреса нет: UDP-сокет слушает `0.0.0.0:6510` и отвечает
на адрес, с которого пришёл `EgmRobot` (`recvfrom`, ADR-009 в `docs/09-decisions.md`).
Поэтому для реального контроллера пересобирать приложение не нужно — адрес живёт
только в конфигурации контроллера:

* виртуальная система: `Controller → Configuration → Communication → UCdevice`;
* реальный контроллер: `/SYSPAR/SIO.cfg` по FTP + рестарт системы;
* в этом репозитории живого `SIO.cfg` нет — конфигурация упакована в
  `RobotStudio\FrezaEGM\Systems\FrezaEGM\INTERNAL\image.bin`; рядом лежат только
  резервные копии `RobotStudio\FrezaEGM\Backups\<дата>\SYSPAR\SIO.cfg`.

## Чей это адрес — важное предупреждение

`RemoteAdress` — это адрес **ПК-сенсора**, куда контроллер отправляет `EgmRobot` и с
которого ждёт `EgmSensor`. Это **не адрес робота**.

* Если `192.168.125.1` — адрес **ПК**, который слушает приложение, файл можно
  использовать как есть.
* Если `192.168.125.1` — адрес **робота** (типичный сервисный порт ABB), то на ПК
  надо задать, например, `192.168.125.100/255.255.255.0`, а в `-RemoteAdress`
  вписать **адрес ПК** (`192.168.125.100`). С адресом робота контроллер будет
  отправлять EGM сам себе, и приложение останется в состоянии «ожидание контроллера».

## Как применить

1. **Виртуальный контроллер (RobotStudio):** `Controller → Configuration →
   Communication → UCdevice → RemoteAdress` → нужное значение → `Save` → перезапуск
   контроллера. Отдельный файл для этого не нужен.
2. **Реальный контроллер:** остановить систему, положить файл в `/SYSPAR/SIO.cfg`
   (FTP), выполнить холодный старт. Перед заменой сохраните исходный `SIO.cfg`.
3. Альтернатива для реального контроллера: RobotStudio → `Controller →
   Configuration` → правка параметра → `Save` (нужна опция `616-1 PC Interface`).

Файл добавлен как подготовленный, резервные копии в `Backups\` не изменялись:
они защищены тестом `freza_protected_baseline`.
