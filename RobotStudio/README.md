# RobotStudio 6.08: файлы для станции

Здесь лежит всё, что нужно, чтобы открыть станцию, создать систему RobotWare 6.08
и запустить EGM-обмен.

| Файл | Назначение |
|---|---|
| `ModuleEGM.mod` | RAPID-модуль: `MoveJ home` (toolPencil) → `EGMSetupUC … "UCdevice" \Pose` → `EGMActPose` → `EGMRunPose` → `EGMReset` |
| `FrezaEGM\` | сама станция (`FrezaEGM.rsstn`): робот IRB1600-10/1.45, без контроллера |
| `config\` | подготовленный `SIO.cfg` с адресом EGM `192.168.125.1` и пояснение, как его применить |
| `FrezaEGM\Systems\FrezaEGM` | образ системы 6.08 с опцией EGM (конфигурация внутри `INTERNAL\image.bin`) |

Пакетов `SolutionEGM.rspag` / `SolutionEGM_6.08.rspag` в этой копии проекта нет —
они не нужны: система создаётся из станции (см. ниже).

## Что важно в модуле

* `home = [[750, 0, 600], [0, 1, 0, 0], …]` — первая точка `data\trajectory.gcode`,
  инструмент смотрит вниз. При Z = 300 и ориентации «вверх» контроллер выдавал
  `50456 Close to singularity`.
* `PERS tooldata toolPencil` — TCP на кончике карандаша (280 мм по Z). Модель
  `toolPencil` в станции — только графика.
* `\X \Y \Z` без `\Rx \Ry \Rz`: ориентация не управляется. С поворотами контроллер
  доворачивает инструмент и робот уходит с траектории.
* `\MaxSpeedDeviation:=1000.0` — снимает низкий лимит скорости по умолчанию, без него
  поле «скорость» в приложении не работает.
* `\CondTime:=1` — сессия живёт, пока идут точки; одна сессия на один запуск программы.
* При загрузке модуля RobotStudio показывает диалог **Synchronize to Station** —
  ничего не отмечайте, просто `OK`.

## Почему в старой копии правили пакет

Историческая справка: исходный `SolutionEGM.rspag` содержал **систему RobotWare
6.13.0164**, а установлен RobotWare **6.08.1040**; RobotStudio 6.08 не умеет работать
с системами 6.13, поэтому пакет не открывался. Пакет `SolutionEGM_6.08.rspag` был тем
же пакетом без системы. В текущей копии проекта обоих файлов нет.

## Порядок действий (кратко)

1. Открыть станцию `FrezaEGM\FrezaEGM.rssln` или `FrezaEGM\Stations\FrezaEGM.rsstn`.
2. Создать виртуальную систему 6.08.1040 с опциями **616-1 PC Interface** и
   **689-1 EGM**, если её ещё нет (`Home → Robot System → From Layout`).
3. Запустить контроллер, дождаться `Running`.
4. `RAPID → T_ROB1 → Program Modules` → добавить модуль из файла `RobotStudio/ModuleEGM.mod`.
5. `Check program` → 0 ошибок; `PP на main`.
6. В приложении FrezaEgm — «Запустить траекторию» (порт 6510), затем в RobotStudio `Start`.

Подробности и типичные ошибки — в `docs/06-robotstudio-setup.md`,
полная инструкция — `docs/12-runbook.md`.
