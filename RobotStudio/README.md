# RobotStudio 6.08: файлы для станции

Здесь лежит всё, что нужно добавить в станцию RobotStudio 6.08.01 после того,
как она открыта и для неё создана система RobotWare.

| Файл | Назначение |
|---|---|
| `ModuleEGM.mod` | RAPID-модуль: `MoveJ home` (toolPencil) → `EGMSetupUC … "UCdevice" \Pose` → `EGMActPose` → `EGMRunPose` → `EGMReset` |
| `FrezaEGM\` | сама станция (`FrezaEGM.rsstn`) + созданная система `Systems\FrezaEGM` с опцией EGM |
| `../SolutionEGM_6.08.rspag` | исправленный пакет станции под RobotStudio 6.08 (без системы RobotWare 6.13) |

## Что важно в модуле

* `home = [[750, 0, 600], [0, 1, 0, 0], …]` — первая точка `data\trajectory.gcode`,
  инструмент смотрит вниз. При Z = 300 и ориентации «вверх» контроллер выдавал
  `50456 Close to singularity`.
* `PERS tooldata toolPencil` — TCP на кончике карандаша (280 мм по Z). Модель
  `toolPencil` в станции — только графика.
* `\X \Y \Z` без `\Rx \Ry \Rz`: ориентация не управляется. С поворотами контроллер
  доворачивает инструмент и робот уходит с траектории.
* `\MaxSpeedDeviation:=1000.0` — снимает низкий лимит скорости по умолчанию, без него
  поле «скорость» в приложении не работает.
* `\CondTime:=1` — сессия живёт, пока идут точки; одна сессия на один запуск программы.
* При загрузке модуля RobotStudio показывает диалог **Synchronize to Station** —
  ничего не отмечайте, просто `OK`.

## Почему пакет пришлось исправлять

Исходный `SolutionEGM.rspag` (он же `Egm/SolutionEGM.rspag`) содержит **систему
RobotWare 6.13.0164**, а установлен RobotWare **6.08.1040**. RobotStudio 6.08
не умеет работать с системами 6.13, поэтому пакет не открывался.

В исправленном пакете осталась сама станция, а система 6.13 удалена: при первом
открытии RobotStudio предложит создать для станции новую систему на 6.08.

## Порядок действий (кратко)

1. Открыть станцию `FrezaEGM\FrezaEGM.rssln` (система уже создана с опцией EGM).
2. Запустить виртуальный контроллер.
3. `RAPID → T_ROB1 → Program Modules` → добавить модуль из файла `RobotStudio/ModuleEGM.mod`.
4. `Check program` → 0 ошибок; `PP на main`.
5. В приложении FrezaEgm — «Запустить траекторию» (порт 6510), затем в RobotStudio `Start`.

Подробности и типичные ошибки — в `docs/06-robotstudio-setup.md`,
полная инструкция — `docs/12-runbook.md`.
